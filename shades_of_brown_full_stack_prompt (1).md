# Shades of Brown Cafe — Feature-by-Feature Full-Stack Development Prompt

## Project Overview

I am building a real-world cafe website and ordering system called **Shades of Brown**.

The application will use:

- **Backend:** Django + Django REST Framework
- **Frontend:** React + Vite
- **Database:** Start with SQLite for development, but keep the architecture easy to migrate to PostgreSQL later.
- **Authentication:** JWT for admin/staff
- **Image handling:** Pillow / Django media
- **Frontend API communication:** Axios or fetch
- **Styling:** Modern responsive CSS. Use a warm, premium, aesthetic visual identity with a **mild brown gradient**, cream/off-white surfaces, elegant typography, subtle animations, and good spacing.

The application should feel like a **premium, cozy, modern cafe**, not like a generic food-ordering template.

The cafe brand is:

> **Shades of Brown**

The overall design should communicate:

- Coffee
- Warmth
- Conversations
- Cozy atmosphere
- Premium but approachable
- Modern cafe experience
